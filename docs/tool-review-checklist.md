# IP Toolbox 工具审核与上线确认清单 (Review Checklist)

每一款候选软件在正式合并进 `ip-toolbox` 代码库之前，都必须由审核人员进行严格的人工过滤。此清单旨在确保收录库的长效安全、可信与高价值。

---

## 1. 官方来源检查 (Official Source Check)
- [ ] **域名验证**：软件提供的 `officialUrl` 是否为项目开发商或开源团队的真实官方主页？
- [ ] **防冒充**：是否存在搜索引擎竞价排名伪造的非官方下载页？（如各种带有 `.cn`、`.net` 伪装的中文特供版网站）
- [ ] **项目归属**：如果是 GitHub 项目，`githubOwner` 和 `githubRepo` 必须是该项目的核心维护源（优先官方仓库，拒绝无信用的民间二次 Fork 仓库）。

## 2. 项目活跃度检查 (Project Activity Check)
- [ ] **维护状态**：项目是否已明确宣告死亡或被废弃（Archived / Deprecated）？
- [ ] **更新频率**：对于开源软件，最后一次 Commit 或 Release 是否距离当前过长（例如超过 2 年无任何维护），如果是，评估其是否存在系统兼容性问题。
- [ ] **Issue 响应**：官方仓库是否堆积了大量未解决的致命 Bug 或安全漏洞报告？
- [ ] **社区背书**：商业软件是否有足够的知名度和基础用户盘？开源软件是否具备一定的 Star 基础？

## 3. 下载安全检查 (Download Security Check)
- [ ] **直链验证**：`downloadUrl` 必须直接指向 `.exe`, `.dmg`, `.zip` 等最终文件格式，严禁跳转第三方广告盘或需要登录网盘才能下载。
- [ ] **官方构建**：对于开源项目，必须采用 GitHub Releases 页面中官方自动构建（CI/CD）的资产，严禁使用其他人编译打包的产物。
- [ ] **格式纯洁度**：排除任何所谓的“绿色免安装修改版”、“破解补丁版”、“汉化去广告版”。
- [ ] **流氓捆绑**：商业或免费软件在安装时，是否默认勾选（且极难取消）安装各类流氓安全卫士或主页锁定工具？（若是，直接一票否决）。

## 4. 用户价值判断 (User Value Judgment)
- [ ] **场景匹配**：该工具是否精确击中了我们设定的 5 大核心用户受众（`跨境用户`, `内容创作者`, `普通电脑用户`, `AI 用户`, `开发者`）之一？
- [ ] **真实需求**：它是否解决了一个核心痛点，或者在细分领域内具备不可替代性（或极高性价比）？
- [ ] **描述准确性**：录入的 `shortDescription` 和 `fullDescription` 是否客观、中立，没有使用“全球第一”、“碾压”等传销式营销话术？

## 5. 上线前确认 (Pre-launch Confirmation)
- [ ] **数据结构合规**：该工具的 `.ts` 配置文件是否完全遵循了 `src/data/tool-template.ts` 的结构规范？
- [ ] **类型无误**：`audiences` 和 `platforms` 的数组取值是否严格落在联合类型定义之内？
- [ ] **测试通过**：将工具数据合入 `src/data/tools.ts` 并运行 `npm run lint` 和 `npm run build`，是否 0 错误通过？
- [ ] **本地呈现**：运行 `npm run dev`，在本地环境确认首页卡片显示正常、组合筛选功能无异常、详情页下载链接可点击。
